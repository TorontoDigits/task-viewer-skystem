# SkyStem Task Viewer / Task Master

A browser-based task management prototype designed for handling tasks, subtasks, checklists, assignments, comments, document uploads, and workflow tracking in a single interface.

---

# Technologies Used

- HTML
- CSS
- TypeScript
- JavaScript

---

# Project Structure

```text
task-viewer-skystem/
├── images/
│   └── logo-skystem.png
├── .gitignore
├── package.json
├── package-lock.json
├── script.ts
├── script.js
├── SkyStem Task Master.html
├── style.css
└── tsconfig.json
```

---

# Features

- Task and subtask management
- Checklist handling
- Task status tracking
- Owner, reviewer, and approver assignment
- Due date calculations
- Comment management
- Task document uploads
- Completion document support
- Linked account handling
- Column visibility customization
- Sorting and drag-and-drop ordering
- Browser save/load support
- Import and export functionality

---

# Requirements

Before running the project, make sure the following are installed:

- Node.js
- TypeScript

---

# Installation

Install the required dependencies:

```bash
npm install
```

---

# Compile TypeScript

Compile the TypeScript files using:

```bash
npx tsc
```

For automatic recompilation during development:

```bash
npx tsc --watch
```

---

# Run the Project

After compiling, open the following file in your browser:

```text
SkyStem Task Master.html
```

You can open it directly or use a local development server.

---

# Development Workflow

1. Edit `script.ts`
2. Run the TypeScript compiler
3. Open the project in the browser
4. Test changes
5. Continue development
